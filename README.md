# Muhammad Irsyaduddin Firdaus's Portfolio Website

Hi I'm Muhammad Irsyaduddin Firdaus Bin Jumai. Interested in my work? Please read below.

## Description

A personal portfolio website built to showcase my experience, projects, and skills as a software developer, and to give recruiters and collaborators an easy way to reach me. Built with React, Vite, and Tailwind CSS, and designed to be fully responsive.

## Features

- Responsive design across mobile, tablet, and desktop
- Interactive, swipeable skills carousel
- Featured projects with live demo links
- Work experience and education timeline
- Direct links to email and LinkedIn
- Smooth scroll navigation with an active section indicator

## See It Live Here

https://irsyaduddin-firdaus-portfolio.vercel.app/

## Technologies Used

- React 19
- Vite
- Tailwind CSS v4
- Framer Motion
- Lucide Icons

## Usage

- Navigate through the sections using the menu
- View project details, including live demos, in the Projects section
- Browse skills by category using the carousel
- Reach out directly through the Email or LinkedIn links in Contact

## Folder Structure

- `/public`: static assets (resume, favicon)
- `/src/components`: UI components (Navbar, Hero, About, Experience, Projects, Skills, Education, Contact, Footer)
- `/src/data`: site content
- `/src/hooks`: custom hooks (typewriter effect, scroll spy navigation)
- `/src/index.css`: theme colors, fonts, and animations
